# Chuyển toàn bộ AI sang Groq

Yêu cầu cập nhật của người dùng: bỏ Gemini, chỉ dùng Groq cho mọi tính năng. Yêu cầu này thay thế phần Gemini/Google Search trong đặc tả ban đầu.

- [x] Viết kiểm tra tạo bài qua Groq Chat Completions JSON mode, phân loại hợp lệ, từ chối bài chưa hoàn chỉnh và nguồn do model tự bịa; xác nhận kiểm tra thất bại trước khi sửa.
- [x] Chuyển tạo nháp thủ công/hàng loạt và cron sang cùng cấu hình Groq với chatbot; giữ kiểm tra nội dung, chuyên mục và chống tạo nháp trùng.
- [x] Xóa mã Gemini, giao diện cài đặt, điều kiện khóa Gemini và xử lý lỗi riêng của Google.
- [x] Migration chỉ xóa khóa/model của nhà cung cấp đã bỏ; xác nhận cấu hình Groq và bài viết không thay đổi.
- [x] Cập nhật hướng dẫn về nguồn: không có truy cập web tự động trong tạo nháp; chatbot tiếp tục dẫn nguồn blog đã xuất bản.
- [x] Kiểm tra với API thật, production build và HTTP; khởi động lại web local và giữ server hoạt động. 26 unit test, 12 integration check, 19 HTTP smoke check đều qua; tạo bài qua HTTP bằng khóa thật lưu nháp thành công và fixture đã được dọn. Review độc lập không phát hiện lỗi trong phạm vi thay đổi.
